# 法典笔记

**中文** | [English](README.en.md)

**法解释的方法，就是法律人的学习方法。**

法典笔记是一本按法解释方法组织的个人法典笔记。读一条条文，先弄清字句的意思（文义解释），再把它放回整部法典中看（体系解释），看它怎样制定和修改（历史解释），想它要实现什么目的（目的解释），参照外国的规定（比较法解释），最后写下自己的判断。现在收录三部法典：宪法（1982—2018 年各年文本）、民法典，以及合编《网络安全法》《数据安全法》《个人信息保护法》的网络法典。

笔记中的解释是学理解释，不具有法律效力。

## 六个原则

法解释方法决定怎样读条文；软件本身，按六个原则构建，二者同样重要：

| 原则 | 在软件中的体现 |
| --- | --- |
| **个性化** | 条旨、使用说明、解释标签都可以按自己的理解改写，修改前的内容保留 |
| **智能化** | 智能辅助整理材料、提出线索；编程助手可以按你的要求修改软件。判断由自己作出 |
| **可塑性** | 源代码是普通的 HTML、CSS 和 JavaScript，随软件提供，可以增删、改变功能 |
| **可扩展** | 法典的正文、目录和专属功能放在[数据包](demo/codes/README.md)里，可以继续扩展到刑法等其他法典和立法 |
| **去中心化** | 不依赖服务器和账号，笔记经网盘或文件在设备之间传递 |
| **本地化** | 笔记存在自己的设备上，随时导出 JSON 和 Markdown，带到其他软件（见[数据格式](demo/数据格式.md)） |

## 功能

三部法典共用阅读、笔记、搜索和导出功能；修正对照、官方英文译本、备案审查等内容按各数据包提供。

- **体系阅读**：按编、章、节读整部法典，可以自己划分部分，写明部分之间的关系。目录分层折叠，可以按条号或条旨查找。
- **法条精读**：逐条阅读，选词写笔记、建立词条和关联；修正对照、历次修正；官方英文译本对照；记忆卡片。
- **关联阅读**：词条与条文关联、新知导入、材料关联，以及：
  - **比较阅读**：输入一个概念或外国宪法条文，或导入外国宪法、论文，与条文、章节或整部宪法建立关联。
  - **备案审查**：全国人大常委会法制工作委员会备案审查工作报告和审查案例中援引宪法条文的段落，按条文排列，可以据此写审查笔记。
- **我的笔记**：按条文或时间排序，待核清单，方法回顾。
- **导出同步**：导出 JSON 和 Markdown；把整个文件夹放进网盘即可在几台电脑之间同步。

## 版本选择与使用

**第一次用、没有电脑基础的同学，请直接看[安装与使用说明](各终端安装说明.md)**，里面每一步都写清楚了。

所有版本都包含宪法、民法典、网络法典三部法典，笔记只存在自己的设备上。下载地址：[最新版本](https://github.com/sunspearyb/code-notes/releases/latest)，在页面下方 Assets 中选择。

| 设备 | 推荐 | 文件 |
|---|---|---|
| 苹果电脑 | Mac 版 | `fadian-notes-mac-版本号.dmg` |
| Windows 电脑 | Windows 版 | `fadian-notes-windows-setup-版本号.exe`（免安装：`-portable-`） |
| 安卓手机 | 安卓版 | `fadian-notes-android-版本号.apk` |
| 苹果手机、iPad、鸿蒙 5 以上的华为手机 | 手机网页版 | 下方网址 |
| 提取 PDF 文字、接入 AI 助手、网盘同步 | 电脑网页版（PC&Mac 通用版） | `fadian-notes-pc-mac-版本号.zip` |

Mac 版、Windows 版、安卓版是一个应用包含三部法典，点左上角法典名称旁的 ▾ 切换，各法典的笔记分开保存。以前单独安装过民法典版、网络法典版的，见安装说明第五节，把笔记搬到新应用。

### 手机网页版

三部法典各有一个网址，在 Safari（苹果）或 Chrome（安卓）中打开，添加到主屏幕：

- [宪法](https://sunspearyb.github.io/code-notes/)
- [民法典](https://sunspearyb.github.io/code-notes/civil-code/)
- [网络法典](https://sunspearyb.github.io/code-notes/cyber-law/)

首次联网完整加载后可以离线使用。不要使用无痕模式；清理网站数据前先导出备份。每周分别导出三部法典的 JSON，存到自己的网盘。

### 只读预览

只想查看条文时，可打开[只读预览目录](https://sunspearyb.github.io/code-notes/preview/)：[宪法](https://sunspearyb.github.io/code-notes/preview/constitution/)、[民法典](https://sunspearyb.github.io/code-notes/preview/civil-code/)、[网络法典](https://sunspearyb.github.io/code-notes/preview/cyber-law/)。预览页面仅供阅读，不加载笔记程序，不提供输入、上传、导入或保存功能，与正式手机版分开。

### 自行部署

网页部署包（Release 中的 `fadian-notes-web-版本号.zip`）供网站维护者上传到自己的 HTTPS 网站，包含网页、图标、应用清单和离线缓存脚本。普通用户不需要下载此包，它不是手机安装包。部署三部法典可参照仓库的 Pages 工作流，从源码分别生成。

## PC&Mac 通用版

### 打开

- **不装任何软件**：用 Chrome 或 Edge 打开 `demo/法典笔记.html`。可以阅读和写笔记；在“导出同步”中选择本文件夹，笔记会自动写入文件夹中的 `法典笔记数据.json` 和 `法典笔记.md`。
- **完整功能**：需要 Python 3.9 或以上版本。
  - Mac：双击「打开法典笔记.command」。第一次运行时，系统如果提示安装“命令行开发者工具”，按提示安装即可，它包含 Python 3。
  - Windows：先从 [python.org](https://www.python.org/downloads/) 安装 Python，安装时勾选“Add python.exe to PATH”；再双击「打开法典笔记.bat」。
  - 浏览器会打开 `http://127.0.0.1:8766/`。使用期间保持启动窗口打开，关闭窗口即停止。这个网址只在本机使用。

Mac 第一次双击 .command 文件时，系统可能提示无法打开：打开“系统设置 → 隐私与安全性”，在页面下方点“仍要打开”。

### 在几台电脑之间同步

把整个法典笔记文件夹放进 Dropbox、百度网盘或阿里云盘的同步文件夹。用启动文件打开时，笔记保存在文件夹中的 `.fadian-clean-local/`，并写出 `法典笔记数据.json` 和 `法典笔记.md`；网盘把它们同步到另一台电脑。

- **不要在两台电脑上同时打开。** 在一台上写完、关闭，等网盘同步好，再到另一台打开。
- 两台电脑都改过时，有差异的记录都会保留，不会互相覆盖；网盘生成的冲突副本会自动合并。

升级到新版本：解压新版本，把旧文件夹中的 `.fadian-clean-local` 文件夹和 `法典笔记数据.json` 复制到新文件夹，再用新文件夹替换旧文件夹。也可以先导出 JSON，在新版本中导入。

### 资料与智能辅助

在「关联阅读 → 新知导入」上传资料，选择关联范围，自己写关联理由，或请智能辅助先提建议。在「智能辅助」中可以接入能运行本机命令的助手（Claude Code、Codex 等），也可以填写自己的模型接口和密钥；密钥只保存在本次运行的内存中，不写入文件。

TXT、Markdown、DOCX 可以直接提取文字。PDF 需要可选组件 pypdf：`python3 -m pip install -r requirements-optional.txt`（Windows 把 `python3` 换为 `py -3`）。扫描件需要另行识别文字。

## 修改和扩展

- 请编程助手修改：先让它读 [AGENTS.md](AGENTS.md)。
- 自己修改：界面在 `demo/src/`，法典数据在 `demo/codes/`。改完运行 `python3 demo/build.py` 生成页面，`node demo/test-clean.cjs` 等测试检查。
- 扩展到其他法典：见[数据包说明](demo/codes/README.md)。
- 提建议、报告错误、指出条文勘误：在 [Issues](../../issues) 中选择对应的模板。参与修改见 [CONTRIBUTING.md](CONTRIBUTING.md)。
