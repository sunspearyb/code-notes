## 提取与校验方法

`build_versions.py`从命令行接收原始文件路径，先校验SHA-256，再读取DOCX正文XML。仅删除段首段尾空白，以及从正文分离条号所需的空白。正文词语、标点、分款和分项保持原样。条文内的括号、书名号及原有空格不作统一替换。

`sourceParagraphs`是DOCX正文中从1开始的段落位置，空段也参与位置计数；它不是款号或页码。`sourceFile`对应上述源文件。每个版本的全文、条号顺序和目录范围均有程序检查。重复运行的JSON文件已经逐字节比对。

民法典共1260条、2126个正文段落、137个目录节点。七编及附则的起止条号全部符合官方文本；目录标题与正文标题逐字一致。物权编、合同编的章号在各编内跨分编连续，已核对。数据库所示现行文本为2020年通过文本，本包版本为`[2020]`。

```sh
python3 demo/codes/civil-code/build_versions.py --source /path/to/civil-2020.docx
```

## 官方英文译本

来源：[全国人大英文网站公布的Civil Code PDF](http://en.npc.gov.cn.cdurl.cn/pdf/civilcodeofthepeoplesrepublicofchina.pdf)，229页，1260条。下载日期2026年10月18日。SHA-256：`eecd83ed885676d77ea5e2939e687307c3fe4454bd803243161f87c734863521`。

使用`pdfplumber`按文本坐标提取，依据缩进恢复段落、合并行内排版换行，并逐一核对1—1260条与中文条号的对应。保留各条PDF页码。已查看PDF版面并抽核各编边界、最后两条及异常短段。第84、118页在第462、647条之后、下一编章标题之前，各有一个独立句点；已将其记录为版面残留，不并入条文，位置见`validation.excludedLayoutMarks`。

英文提取依赖`pdfplumber`；中文版构建仅用Python标准库。重建命令：

```sh
python3 demo/codes/civil-code/build_english.py --source /path/to/civil-english.pdf
```

全国人大英文网站链接使用其公开内容域名`en.npc.gov.cn.cdurl.cn`；本包保留实际下载地址和文件校验值。英文为官方参考译文，适用及引用以中文本为准。

## 待使用者确认的内容

2026年10月18日，按使用者“每条的小标题，请你根据条款内容草拟”的要求，将全部条旨草稿载入`subtitles.json`，供正文、目录和检索使用。条旨均依据本条内容独立拟定，为4—10字，未采用商业出版物的标题。`subtitles-draft.json`保留同一版初稿，未直接列入构建清单。欢迎页和使用说明注明草稿性质；使用者可逐条修改。

研读六步的六个例题均显式标为“例题草案，待使用者确认”。每项所用条文、问题设置和学理联系，见同目录[例题审阅稿](例题审阅稿.md)。未把草案写成个人笔记。

中文法律的通过、修正、施行日期及条数已完成来源核实。尚待确认的是条旨和例题的学术取舍。
