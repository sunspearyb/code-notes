# 法典笔记介绍视频：解说词

竖屏 1080×1920，约 2 分 50 秒。画面和解说词在[场景.json](场景.json)中，改动后运行：

```sh
python3 维护工具/介绍视频/制作视频.py --out 分发/法典笔记介绍视频-新版本号.mp4
```

现在的配音是 macOS 的合成语音“婷婷”，只作占位。建议用你自己的声音录一遍：每一句录成一个音频文件，按下表的文件名放进 `维护工具/介绍视频/配音/`（支持 m4a、wav、mp3、aiff），再运行上面的命令，视频会按录音的长短重新排时间。没有录的句子，仍用合成语音。手机的“语音备忘录”录的 m4a 就可以。

课堂引文照录《第一部分》课件第 2 页“在大学如何学习”、第 5 页“人工智能使用原则”。

## 字幕与发布

- 制作工具同时生成同名 `.srt` 字幕文件。视频画面已经带字幕，上传到不支持外挂字幕的平台时，不必另传。
- 画面中的笔记是为视频写的两则示例（第三十七条“人身自由”、第三十八条与德国《基本法》第一条的比较），不含任何个人笔记。
- 没有使用背景音乐。需要配乐时，请选用有授权的音乐，在剪辑软件中加入。
