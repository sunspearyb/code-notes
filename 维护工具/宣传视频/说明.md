# 宣传视频

与 `维护工具/介绍视频/`（讲操作的竖屏介绍片）不同，这里是宣传片：讲理念，不讲按钮。

画面不是录屏。`渲染.html` 能画出影片中任意一秒的画面，`抓帧.mjs` 在 Chrome 中逐帧取图，`渲染.py` 用 ffmpeg 合成，`配乐.py` 用纯计算生成声音（低音铺底、转场纸声、落版单音），不使用任何音乐素材，无版权问题。同样的输入每次得到同样的影片。

## 经验（A、B 两片三轮修改后总结，C、D 片按此制作）

1. **留够阅读时间。** 画面上的文字至少按每秒 6 个汉字计时，再加 1.5 秒停留；底部说明文字不超过 25 字。一步只讲一件事，讲完再走下一步。分场时长写在 `场景.json` 的 `scenes` 中，配乐的转场和重音按分场相对时间自动对齐，改时长不必改代码。
2. **一处焦点。** 同一时刻只点亮一组内容，其余调暗；颜色按解释方法区分（文义天蓝、体系玉绿、历史琥珀、目的珊瑚、比较法淡紫、法权朱红），全片不超过三种强调色同时出现。
3. **中心要大。** 体系图的中心节点是全片的锚，要比周边节点大一个量级（第十三条的圆半径约 118 像素）。
4. **例子要典型，出处要可查。** 优先用课件、使用说明里已有的例子：1983 年国家安全机关决定、第十一条三次修正、2019 年“通讯记录”案。条文、修正增删、修正案条号都由程序从数据包读取；引文逐字核对原文。
5. **学理要稳。** 法权分析只画条文里确有的关系，画面注明“示意，不是对本条的分析”；不在画面上删除或否定使用者主张的方法。
6. **先看静帧，再渲整片。** `--stills` 抽查每一场，确认无重叠、无行首标点（排版已遵守行首禁则）后再整片渲染；整片可以并行渲染。
7. **每片一种配乐。** 风格贴合内容，音量统一在平均约 −18 dB。

8. **文字动效不用下划线。** 标题、理念、落版逐字出现，每个字由模糊变清晰、略微上浮；关键词只用变色加柔和发光（呼吸式明暗）表示，不加下划线、删除线。要“退后”的词（如“机械摘抄”）只变暗。时间轴、刻度、进度条属于图形，保留。

## 竖屏版

竖屏版用于抖音等短视频平台。它有自己的一组场景（`渲染.html` 中以 `v` 开头的函数），按手机屏幕重新设计，不是把横屏缩小。各片的分场、文字、重音和封面写在 `场景.json` 的 `portrait` 中（`short: true`）。命令：

```
python3 维护工具/宣传视频/渲染.py --film A --portrait
```

成片名为 `法典笔记宣传片A-条文不是孤岛-竖屏-20261103-r3.mp4` 等（B 片仍为 `竖屏-20261020-r2`）。2026-10-19 的第一版竖屏（`…-r5-竖屏.mp4` 等）保留不动，它所用的排版设置留在 `portrait_20261019` 中备查。

短视频的做法：

1. **开头 3 秒抛出问题。** 先用大字提一个问题（如“读法条，最怕只读一条”“AI 都能写笔记了，你还要自己记吗？”），再出片名。第一帧就有字，不从空屏淡入。
2. **三段式版面，避开平台遮挡。** 平台的状态栏和顶部标签约占顶部 200 像素，标题、点赞按钮和文案约占底部 360 像素和右侧一列。所以：
   - 章节进度条放在 y≈214；
   - 每场的标题（问题或名称）放在 y≈340，下面一行小标题；
   - 主画面放在 y 470–1400；
   - 字幕放在 y 1480–1560；
   - 出处、注释等小字放在 y≈1640。
3. **字要大。**
   - 字幕 50–64 像素，加粗；
   - 每场标题 80 像素，宋体黑；
   - 开场问题 100 像素以上，片名 150 像素；
   - 图中标签不小于 30 像素，只有出处等小字用 28 像素。
4. **一屏只讲一件事。** 横屏一屏并列的内容，竖屏改为先后出现，比如：
   - D 片“外包”和“辅助”先后各占一屏，最后才并排对比；
   - B 片“比较法视野”的镜头沿光束在两个球体之间移动，每次只看一个球体。
   体系图里，没点亮的节点只显示名称；点亮哪条线索，才显示那条线索上各节点的注释，并在字幕里讲出这条线索。
5. **节奏快，不留空屏。** 每场开头有 0.45 秒的轻推镜头，结尾只淡出 0.28 秒。各场时长压缩：A 片 120 秒，B 片 117 秒，D 片 98 秒。
6. **顶部常驻章节进度。** 例如 B 片显示“文义 · 历史 · 目的 · 比较 · 方法”，当前一章亮起，观众知道看到了哪里、后面还有什么。
7. **结尾引导互动。** 落版下方提一个问题，请观众在评论区回答，比如“你最常用哪一种解释方法？”。
8. **封面单独设计。** 片名分两行，用很大的字号，适合在缩略图列表里辨认。

动效规范不变：逐字由模糊变清晰；关键词只变色加发光。历史解释的修正对照也不用删除线：增加的字用绿色高亮，删去的字用红色并变暗，屏幕下方有一行图例说明。

## 短片

在视频号上发了 A 片竖屏版之后，平台数据（2026-11-05）是：3 秒以上播放率 51.6%，完播率 5%，第 12 秒观看率明显下降；互动率、转发、关注都很高。据此，从三片里只拆出动画效果最强的场景，做成 20–40 秒的短片。以法条文字为主的段落不用。

| 短片 | 来自 | 场景 |
|---|---|---|
| A1 一条宪法，连着多少部法？ | A | 第十三条体系图、56 件宪法相关法 |
| A2 一则笔记，怎样长成一张网？ | A | 理性之树、往返穿梭 |
| A3 逮捕的权力，怎样配置才平衡？ | A | 天平 |
| B1 “人格尊严”，各国怎么说？ | B | 比较法视野 |
| D1 你就是数据，数据就是你 | D | 你 / 数据 粒子字 |
| D2 积累的数据，就是模型 | D | 神经网络 |
| D3 法典会换，代码会升，什么不会变？ | D | 外壳、灵魂 |

```
python3 维护工具/宣传视频/渲染.py --film A1      # 短片总是竖屏，输出 分发/法典笔记短片A1-…
```

- **定义**：每支短片在 `场景.json` 中是一个以 `base` 指明母片的条目，文字依次继承母片文字、母片竖屏文字，再加短片自己的文字。
- **开头**（`vClipHook`，2.6 秒）：
  - 学理化的问题第一帧就清楚显示，不逐字浮现；
  - 背后是这一场最好看的时刻，压暗播放，去掉了文字；
  - 文字下面有一条深色衬底。
- **结尾**：落版下方是评论区问题。
- **配乐**：用母片的配乐（A、B、D 风格），重要时刻（`accents`）配上行铃音。第一版（r1）曾试用节拍驱动的电子风格（`配乐.py` 中的 P、G、E、T），用户认为不如原来的配乐，鼓声听起来像枪声，因此不再使用。
- **封面**：一般是片名大字分两行。A2 的封面借用网络热梗（`vcover.meme`）：“我画地为牢，Lawyer / 不可以 / 因为你是那个被宣判的人”，其中“被”字用红笔划掉，意思是法律人不应当画地为牢，而是作出判断的人。A2 第三版把这个热梗做成开头（`vMeme`，7.4 秒）：第一句从第一帧就在，“不可以”从大到小重重落下，画面轻震一下；第三句逐字缓缓出现；两道红线依次划过“被”字。落版下方加一枚斜盖的红色印章“拒绝画地为牢”（`vend.stamp`）。删除记号只用在这个热梗上。
- **发布文案**：每支的描述、话题和置顶评论见 `分发/短片发布文案-20261105.md`。

## 用法

```
python3 维护工具/宣传视频/渲染.py --film A                    # 整片（A、B、C、D），输出到 分发/
python3 维护工具/宣传视频/渲染.py --film B --only 4           # 只渲染第 4 场，审看用
python3 维护工具/宣传视频/渲染.py --film B --stills 9,18,35   # 只导出几个时刻的画面
python3 维护工具/宣传视频/渲染.py --film D --cover-only        # 只重新生成封面
```

文字在 `场景.json` 中修改；条文原文和法律名称由程序从数据包读取，不手抄。已有同名成片时不会覆盖。需要 Google Chrome、Node.js、ffmpeg，Python 需装 numpy（配乐用）。整片约 4 分钟渲染完。

## 视觉规范

- 底色：玉绿 `#123F3A` 到夜蓝 `#141F3C` 的对角渐变，叠两团缓慢漂移的光晕；字为纸白 `#F7F3E8`。
- 朱红 `#F05A3C` 用于“由法律规定”、关系线和法权分析；琥珀 `#F2B544` 用于细线。
- 各解释方法的颜色：文义 天蓝 `#7DB7F5`，体系 玉绿 `#4FD1B0`，历史 琥珀，目的 珊瑚 `#FF8A65`，比较法 淡紫 `#B79CFF`。
- 法条用宋体，编号与说明用无衬线字体；中文排版遵守行首禁则（逗号、句号不出现在行首）。
- 动作只有落版、划线、连线生长三种。缓出、不回弹，每场末尾 0.6 秒淡出。

## 配乐

`配乐.py --style A|B|C|D` 用 numpy 计算生成，不用任何音乐素材。

- A（结构与生长）：D 大调，每分钟 92 拍；拨弦琶音、柔和铺底、轻摇铃。
- B（好奇、轻快）：G 大调，每分钟 116 拍；木琴切分音型，第二、四拍轻拍手。
- C（沉思而不沉重）：F 大调，每分钟 84 拍；柔和的钢琴分解和弦，无打击乐。
- D（向前、有希望）：A 大调，每分钟 104 拍；拨弦琶音，每拍一记轻柔的底鼓。

转场前有一阵轻柔的气声，重要时刻有一串上行铃音，结尾落在主和弦。

### D4《你就是数据，数据就是你，你就是模型》（Remotion，2026-11-05）

把 D1（你 / 数据 粒子字）和 D2（神经网络）合成一支短片。最新为 r5（2026-11-10，38 秒，见本节末尾）：`分发/法典笔记短片D4-你就是数据数据就是你你就是模型-20261110-r5.mp4` 和同名封面；r1–r4 保留。

- **开头**（6 秒）：三句标题不加逗号，上下对齐，一句一句说出来。每句的节奏都是：主语先出现，停半拍，“就是”快速跟上，关键词放大落下并发光，如“你……就是数据”。背景是压暗的“你”。片尾的“你就是模型”用同样的节奏。
- **粒子**：粒子升起，聚成“你”，再变成“数据”，又变回“你”。变形时粒子会向外“呼一口气”。
- **过渡**：组成“你”的粒子沿弧线飞进神经网络的 27 个神经元，到达后换成该层的颜色。前后两段是一个连续的动作，中间没有切换。
- **模型**：网络逐层点亮，模型发光；最后网络虚化，“你就是模型”大字落下。
- **落版**：法典笔记、口号、六个原则，下面是评论区问题。

代码在 `remotion/src/D4/`。`Particles.tsx` 在浏览器里把字形转成点阵；神经元在屏幕上的位置由 `D2/Network.tsx` 的 `neuronScreen()` 提供，粒子才能追着转动的网络飞进去。

```
cd 维护工具/宣传视频/remotion
npx remotion render src/index.ts D4-YouModel 输出.mp4 --gl=angle
npx remotion still src/index.ts D4-Cover 封面.png --gl=angle
```

配乐用 D 风格，即原来的配乐，加了三种柔和的音效和一点混响。三种音效都没有打击声：
- `whoosh`：风声，在“你”与“数据”变形和粒子飞向网络时；
- `shimmer`：一串细碎的高音，像光点，在粒子聚拢时；
- `bloom`：主和弦渐强，配温暖的低音，在模型点亮时；
- `--reverb 0.22`：小厅混响。

原有各片不受影响：`--reverb` 默认为 0，新音效只在写进 `--sfx` 时出现。命令：

```
python3 配乐.py remotion/public/d4-配乐.wav 36 --style D --reverb 0.22 --cuts 6,30.5 \
  --accents 4.55,8.4,11.6,16.0,26.1,28.95,30.7 \
  --sfx 0.95:sparkle,2.65:sparkle,6.1:shimmer,10.4:whoosh,14.6:whoosh,17.4:whoosh,17.8:shimmer,20.1:rise,26.1:bloom,32.9:chime
```

r3 的全面打磨（按画面顺序）：

- 开头背后不再是一张虚化的静帧，而是粒子正在慢慢聚成“你”。
- 正片一开始粒子就从下方涌上来，不再有一秒多的空屏。
- 粒子字有了景深：每个粒子有远近，近的大而亮，整团字缓缓左右摆动；“你”偏暖（玉绿、金、纸白），“数据”偏冷（天蓝、淡紫），变形时颜色随之过渡。
- 粒子飞到神经元时，神经元闪一下白光，再按各自的阈值点亮。
- 去掉了“n / 27 活跃的神经元”计数器（这支片里它和落下的标签重叠），标签从更高处落下。
- 高潮：网络退后时模型不再一起虚掉，而是一道光柱向上冲起，“你就是模型”落在光上。
- 落版加一层缓缓上升的尘埃；全片叠轻微的胶片颗粒。
- 开头到正片改为 10 帧淡入淡出，去掉第一处漏光；第二处漏光减弱。
- 字幕统一不加句号。

注意：`remotion/` 在云盘同步的文件夹里。2026-11-10 发现 Dropbox 把 `node_modules` 复制成了“node_modules 2”（916 MB），并把 `Root.tsx` 还原成脚手架、我的版本成了“冲突副本”。已删除副本并恢复；`tsconfig.json` 只检查 `src/`。如果再出现同名“冲突副本”文件，以时间较新、内容带 D4 的为准。

### r4：3D 版（`remotion/src/D5/`）

用户要求动画更炫、音乐更抓人、氛围更轻快、每 5 秒一个钩子，并同意安装 `@remotion/three`（three、@react-three/fiber）、`@remotion/media-utils`、`@remotion/motion-blur`。

节奏（秒）：0 标题 · 4.5 “你”聚成 · 8.5 “你”炸开重组“数据” · 13.5 光流穿越 · 18 网络点亮 · 23 模型点燃 · 27 落版 · 32 结束。每个钩子处：镜头顶一下并轻震、一圈冲击波、音乐有上升音效和低音涌起；两处最重的钩子（8.5、23）有一瞬白闪。

- `field.ts`：整片粒子场的纯函数：任一秒 → 每个粒子的位置、颜色、大小、亮度；网络 27 个神经元的三维位置与连线；镜头的关键帧轨迹。场景单位：1 = 100 像素，镜头在 z = 20.6、50° 视角时与屏幕 1:1。
- `Scene3D.tsx`：ThreeCanvas。粒子是加法混合的发光点精灵（自定义着色器），拖尾是同一个场在前 0.06、0.12 秒的两份暗影；网络是点精灵（神经元）、加法线段（连线）、沿线跑的信号点；点燃是一根向上的光柱。**叠加到 HTML 底色的方法**：自定义混合让画布 alpha 保持 0、只累加 RGB，浏览器按预乘 alpha 合成时就成了纯粹的加光。
- `YouModel3D.tsx`：HTML 文字层（标题节奏、字幕、落版）、冲击波、画面震动、白闪、颗粒；用 `useAudioData` + `visualizeAudio` 读配乐低频，让粒子、神经元和标题随节拍脉动；“你就是模型”落下时用 `Trail` 做拖影。
- 配乐 `--style U`：A 大调 128 拍，A–F♯m–D–E。柔软的正弦底鼓（无敲击声）、十六分音沙锤、二四拍木边鼓、全速段才加闭镲；每个钩子前 1.6 秒上升音效，钩子上一记低音涌起；三句标题落定处各一声闪光音。命令：

```
python3 配乐.py remotion/public/d5-配乐.wav 32 --style U --hooks 0,4.5,8.5,13.5,18,23,27 --sparkles 0.75,2.05,3.4
cd remotion && npx remotion render src/index.ts D5-YouModel3D 输出.mp4 --gl=angle
```

封面沿用 r2 的设计（`D4-Cover`）。

### r5：回到 r2 重做（`remotion/src/D6/`，配乐 `配乐_r5.py`）

用户认为 r4 丢了理念：“积累的数据，就是模型”一页和一条条笔记的名字没有了，“笔记就是数据”也就没了；r4 的鼓点重音听着奇怪，整体美感不足。r5 以 r2 的结构为底，全片围绕一句话：**累积的一条条笔记是你的数据，用这些数据打造你专属的模型。**

节奏（秒）：0 标题三句 · 6 笔记卡片升起、化成光点聚成“你” · 10.8 “你”变“数据” · 14.4 变回“你” · 17.7 飞进网络 · 18 “积累的数据，就是模型” · 25.2 模型点亮 · 27.6 网络退后、光柱升起 · 30 “模型”落下 · 32.4 落版 · 38 结束。正片每分钟 100 拍（一拍 18 帧），以上时刻都在拍点上。数字集中在 `D6/timeline.ts`，`配乐_r5.py` 开头有同一组数字，改一处要改两处。

- **一条条笔记贯穿全片**：开头标题背后是虚化上浮的笔记卡片；正片里 12 张带种类和名字的卡片（如“笔记 · 宪法 第三十三条”“词条 · 人格尊严”）升起，每张化成一团光点，光点聚成“你”；网络一场里 22 条笔记（种类名与 r2 相同：笔记、词条、关联、解释标签、法权分析、待核问题、修改记录）越来越快地落进输入层，标题下有“已积累 N 条笔记”的计数（到 3,650）。
- **文字**：字幕依次为“一条条笔记，汇成一个你 / 一本笔记，用一生”“你就是数据 / 累积的一条条笔记，是你的数据”“数据就是你 / 存在你自己的文件夹里，由你掌握，随你迁移”“一则一则的笔记，汇聚为你的理性技艺”“用这些数据，打造你专属的模型”。高潮处“你就是模型”落下后，前两句回到它上方，三句合一。
- **粒子**：采样点随机偏移，不再看得出网格；“你”暖（玉绿为主）、“数据”冷（天蓝为主）；变形时旋转并向外呼气；随拍子轻轻亮一下。
- **配乐**（`配乐_r5.py`，numpy 合成，A 大调）：没有重音鼓点，底鼓每拍一记、音量均匀，沙锤和二四拍的轻刷。开头三句的关键词各落一声钟音 A、升 C、E，合起来是主和弦；网络一场里每条笔记落到神经元时响一个木琴音，越来越密、越来越高；“模型”落下时回到主和弦，三声钟音连成一个和弦。响度约 −16 LUFS。

```
python3 配乐_r5.py remotion/public/d4-r5-配乐.wav
cd remotion && npx remotion render src/index.ts D4-R5 输出.mp4 --gl=angle --crf=17
npx remotion still src/index.ts D4-R5-Cover 封面.png --gl=angle
```
